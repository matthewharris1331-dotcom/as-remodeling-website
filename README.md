# A.S. Remodeling website, staging recreation

STAGING ONLY. Do not point asremodelingllc.com at this build, and do not
publish it, until Aleks approves the copy, photos, and form handling.

## Stack, and why

Plain static HTML + CSS, generated by `build.py`. No framework, no
database, no npm, no build server to break.

- Edit: change the copy in `build.py`, run `python3 build.py`, and
  `dist/` is rebuilt. Every page, title, phone link, and footer comes
  from one place, so a fix does not drift across pages.
- Optimize: each page already has its own SEO title and description,
  a sitemap, robots.txt, and LocalBusiness schema. Images are the
  remaining lever: compress approved photos before they go in, and
  keep file names descriptive.
- Monitor: weekly, check (1) Google Business Profile insights,
  (2) Google Search Console once it is connected, (3) the lead log:
  calls, form fills, and booked estimates, (4) that every internal
  link still resolves, and (5) that the phone number and hours are
  still correct. No analytics or tracking code is installed yet on
  purpose: Aleks must approve any tracking first.

This is the opposite of the Squarespace problem. Squarespace has no
content API, its visual editor is the only path, and Muse's browser
edits could not reliably create pages, set SEO titles, or add a
sticky Call Now button. Here Muse edits files directly.

## How to rebuild

```
python3 build.py
```

Deploy the `dist/` folder. Do not edit files in `dist/` by hand;
edit `build.py` and rebuild, or the next build will overwrite them.
